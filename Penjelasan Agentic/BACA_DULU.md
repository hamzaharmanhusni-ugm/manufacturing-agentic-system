# Penjelasan Agentic

Folder ini menjelaskan alur kerja sistem langsung dari tangkapan layar aplikasi yang berjalan. Tampilan aplikasi tidak diubah; nomor, kotak penanda, dan panel penjelasan di sisi kanan ditambahkan di atas gambar.

Urutan baca:

| Berkas | Isi |
|---|---|
| 00a-alur-kerja-garis-besar (PNG, SVG) | Alur kerja secara garis besar: Amati, Pikirkan, Putuskan, Bertindak |
| 00b-alur-kerja-8-langkah (PNG, SVG) | Satu siklus kerja dalam 8 langkah dengan contoh nyata |
| 01 | Control Center: pusat kendali ekosistem |
| 02 | Event memicu empat agent sekaligus (Box 1 sampai 5) |
| 03 | Rencana, penjelasan, dan tanda tangan manusia (Box 6 sampai 8) |
| 04 | Agent registry dan log pesan antar-agent |
| 05 | Live Operations: dunia berjalan sendiri |
| 06 | Sensor membangunkan agent |
| 07 | Rencana menunggu tanda tangan |
| 08 | Tindakan dijalankan: kapal berlayar |
| 09 | Badai memicu perencanaan ulang |
| 10 | Kapal tiba, silo terisi |
| 11 | Audit trail: semua tercatat |

Penjelasan setiap menu aplikasi:

| Berkas | Menu |
|---|---|
| 12, 13 | Simulation Center: enam skenario, docket, timeline paralel, dan tujuh tab analisis |
| 14 | KPI & Analytics: KPI prediksi, KPI sistem agent, sebelum dan sesudah AI |
| 15, 16, 17 | Cement Manufacturing: Executive, Forecasting, Agents |
| 18, 19, 20 | Shipping & Logistics: pelacakan kapal, prediksi ETA, ranking kapal SAW |
| 21 | Distribution: permintaan per wilayah |
| 22 | Supplier & Procurement: risiko pasokan bahan baku |
| 23 | Architecture: diagram alur panggilan dan E_i = (U, M, D, A, P, G) |
| 24, 25 | Governance & Security: RBAC dan kebijakan berbagi data |

Seluruh data bersifat sintetis. Gambar dibuat ulang dengan `python scripts/make_annotations.py` dan `python scripts/make_flow_svg.py`.
